# Materiais das sessões

Uma pasta por encontro: `sessao-01/`, `sessao-02/`, …

Em cada pasta, guarde:

- slides (de preferência em PDF);
- ficheiros de dados e enunciados dos exercícios;
- produtos dos grupos (tabelas, gráficos, textos).

Depois, acrescente a ficha da sessão em [memoria.html](../memoria.html) com as ligações para estes ficheiros.
